Splinklez 1.3.0

- 🌀 颱風路徑潛勢與暴風圈侵襲機率：防災頁新增入口。有颱風時顯示中央氣象署的路徑潛勢（70% 機率半徑範圍）和七級風暴風圈侵襲機率色塊，選縣市就能看到各鄉鎮的侵襲機率；沒有颱風時會直接寫「目前沒有」。
- 🧭 防災設施地圖：找離你最近的避難收容處所、AED、公廁。可以篩選種類、點一下在地圖上定位，「導航」直接開地圖 App。只用粗略位置，送出前會先四捨五入到約 100 公尺；沒開定位就用你設定的城市。
- 🚌 下一班公車桌面小工具：長按桌面加入「下一班公車」，選縣市、路線、方向和站牌，就會顯示到站時間（約每 15 分鐘自動更新，點一下立刻更新，「換站」可以重選）。一個桌面可以放好幾個，各自看不同站牌。
- 🔌 代理人工具：可以替代理人加上自己的 HTTP 工具或連接 MCP 伺服器。金鑰只加密存在伺服器上；會寫入或改動資料的工具，每次都要你按「執行」才會動作，可在「代理人工具」頁確認。
- 新畫面都有讀取逾時＋重試和明確的空白狀態，最下面也留了空間，不會被浮動按鈕擋住。
